# АктОффлайн (MVP)

PWA-приложение для выездных специалистов. Позволяет заполнять акты на месте, получать подпись клиента на экране и работать без интернета с последующей синхронизацией.

## Стек технологий
- **Фронтенд**: React 17, Parcel 1.12.3, Service Worker (PWA), Canvas API.
- **Бэкенд**: Node.js (Fastify 3).
- **База данных**: PostgreSQL (Supabase), ORM Prisma 3.
- **Хостинг**: Vercel (фронтенд), Render (бэкенд).

## Функционал
- Создание заданий (с выбором физ/юр лица и указанием работ).
- Список активных и выполненных заданий.
- Заполнение акта с рисованием подписи пальцем/мышкой.
- Работа в офлайн-режиме (сохранение в LocalStorage).
- Синхронизация данных при появлении интернета.
- Установка на телефон как PWA-приложение.

## Как запустить локально
1. Установить зависимости: `npm install`
2. Создать файл `.env` и указать в нем `DATABASE_URL` (строка подключения к PostgreSQL).
3. Применить схему БД: `npx prisma db push`
4. Запустить бэкенд: `node server.js`
5. Запустить фронтенд: `npm run dev`
